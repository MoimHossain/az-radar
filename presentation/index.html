Accountability / Fit with the operating process

CloudLens supplies the evidence;
your teams own the response.

CloudLens provides the evidence

  • Three source paths & configurable watchlists
  • Structured AI interpretation and guidance
  • Query-derived candidate resource impact
  • Deadline, dashboard and detail views
  • On-demand jobs and execution diagnostics

The organisation owns action

  • Choose review scope and run cadence
  • Validate AI output and candidate matches
  • Assign accountability and set priorities
  • Approve, execute and track remediation
  • Provide access controls and workflow integrations

Appendix / Decision boundaries

Use the output to guide review,
not to certify complete coverage.

AreaEvidence availableDecision boundary
Azure UpdatesFull catalog pagination + RSS reconciliation; revisions detected; full source retained.Not recovery of removed posts, upstream availability, or automatic scheduling.
Microsoft LearnUp to eight unique search results per watched service; hashes available result content.Not every document or every edit; analysis input is bounded.
GitHub RadarSelected repositories/path prefixes; bounded .md/.mdx changes and lifecycle analysis.Not all file types, an exhaustive mirror, dependency inventory or vulnerability scanner.
Impact & calendarUse up to 500 feed items + 500 doc insights. Impact stores up to 20 resource details.Not the entire archive or a complete, paginated estate assessment.
AI & workflowModel-provided severity, guidance and confidence; source and job evidence for review.Not calibrated certainty, a compliance score, ownership routing or executed remediation.
Before relying on an output: confirm source coverage, query scope and freshness.September 2026 implementation
